# react-smart-form

A lightweight React form component library that builds a form from a field configuration array and applies a small set of built-in validation rules before submitting the data.

This repository is not a full application; it is a reusable library package built with React and Vite. The public export is the `Form` component, and the project is configured to bundle it as an ESM/CJS library for use in other React apps.

## Overview

The package exposes a single component, `Form`, from `src/Form.jsx` and re-exports it through `index.js`.

The component:

- accepts a `fields` array describing each form input
- reads submitted values with `FormData`
- validates configured rules for each field
- stores validation errors in local state and renders them beneath the matching input
- calls a `handleSubmit` callback with the submitted data object

## Installation

From the project root:

```bash
npm install
```

This package is intended to be used as a library in a React app, and it declares `react` and `react-dom` as peer dependencies.

## Usage

```jsx
import { Form } from "react-smart-form";

const fields = [
  {
    name: "firstName",
    type: "text",
    placeholder: "First name",
    validations: ["required"],
  },
  {
    name: "email",
    type: "email",
    placeholder: "Email address",
    validations: ["required", "email"],
  },
  {
    name: "password",
    type: "password",
    placeholder: "Password",
    validations: ["required", "password"],
  },
  {
    name: "confirmPassword",
    type: "password",
    placeholder: "Confirm password",
    validations: ["required", "confirm-password"],
  },
];

export default function App() {
  return (
    <Form
      fields={fields}
      handleSubmit={(data) => {
        console.log("Submitted values:", data);
      }}
    />
  );
}
```

## Component API

```jsx
<Form fields={fields} handleSubmit={onSubmit} />
```

### Props

- `fields`: array of field definitions
- `handleSubmit`: callback receiving the form data object

### Field definition shape

```js
{
  name: "email",
  type: "email",
  placeholder: "Email address",
  required: true,
  validations: ["required", "email"]
}
```

Supported field properties used by this implementation:

- `name`: unique input name used as the object key in the submitted data
- `type`: HTML input type, such as `text`, `email`, `password`
- `placeholder`: placeholder text for the input
- `required`: sets the native HTML `required` attribute
- `validations`: array of validation rules applied by the component

## Validation rules

The current implementation supports these validation strings:

- `required`: ensures a value is present; for file inputs, it checks whether a file was selected
- `email`: validates using a simple email regex
- `password`: requires at least 8 characters, at least one uppercase letter, and at least one number
- `confirm-password`: compares the current value to the value of the field named `password`

Validation messages are stored in the component state and displayed underneath the relevant input.

## Behavior notes

This project is intentionally minimal and follows a simple pattern:

- form fields are generated from a JSON-like array
- validation rules are driven by string values in `validations`
- the final payload is built from `FormData` via `Object.fromEntries(formData.entries())`
- the callback receives a plain JavaScript object with key/value pairs

One important implementation detail: the component updates `errors` and renders them in the UI, but it still calls `handleSubmit(data)` after validation runs. If you use it in a real app, you may want to guard the callback in your parent component based on the returned validation state or by adapting the component logic.
